# VRK GATE & ESE Academy — New Website

This is a from-scratch responsive static website for VRK GATE & ESE Academy.

## Files
- `index.html` — all page sections/content
- `styles.css` — complete responsive design
- `script.js` — mobile navigation, year, enquiry form
- `assets/logo.jpeg` — supplied academy logo

## Deploy on Vercel
1. Upload this folder to GitHub, or import the project folder into Vercel.
2. Framework preset: Other / Static.
3. Build command: leave blank.
4. Output directory: `.`
5. Deploy.

## Important
The enquiry form currently opens the visitor's email app and prepares an email to `vrkgate@gmail.com`. For a server-side form, WhatsApp enquiry, Google Forms, or database storage, replace that handler later.

## Easy editing
Most text is in `index.html`; colors and layout are in `styles.css`. You do not need to rebuild the whole site for normal text/image changes.
